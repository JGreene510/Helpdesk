UNINSTALL HELPDESK (VERSION 4)  -  STEP BY STEP, FROM ZERO
==========================================================

You do not need to know anything about computers to follow this.
Go in order. Do not skip steps.

Time needed: about 10 minutes.

IMPORTANT: Uninstalling DELETES your tickets and your logins. If you
might ever want them again, do PART 1 (save a copy) first. It takes
two minutes and cannot hurt.


--------------------------------------------------------------------
FILL THIS IN (the same two blanks as in Install.txt)
--------------------------------------------------------------------

   The Pi's login name  ("PIUSER") ........ ______________________

   The Pi's address     ("PIADDRESS") ...... ______________________
        (looks like  mypi.local  or like  192.168.1.50 )

(Do not remember them? See Install.txt, Part 1: "Find the Pi's login
name and address".)


--------------------------------------------------------------------
WHAT UNINSTALLING DOES - AND DOES NOT DO
--------------------------------------------------------------------

It REMOVES:
   - the Helpdesk program, its folder, and everything in it
   - the "start by itself" setting, so Helpdesk stops running
   - all tickets and all Helpdesk logins (unless you save a copy)

It does NOT touch:
   - the rest of your Pi, its own login, or anything else installed
     on it (for example Pi-hole stays exactly as it is)
   - your router, your other computers, or your Gmail account

Just want to start over with EMPTY tickets (keeping Helpdesk
installed)? Skip to PART 7 instead.


--------------------------------------------------------------------
HOW TO READ THE COMMANDS IN THIS GUIDE
--------------------------------------------------------------------

Indented lines like this are things you TYPE (or copy and paste), and
then press the Enter key:

        like this line

Words in CAPITAL LETTERS (PIUSER, PIADDRESS) are blanks. Swap them
for what you wrote in the box above. Example: if your login name is
"sam" and the address is "mypi.local", then

        ssh PIUSER@PIADDRESS

becomes

        ssh sam@mypi.local

Spaces matter. Type each line exactly as shown.

When you type a password in a terminal, NOTHING appears on the screen.
That is normal. Type it, then press Enter.

To paste in PowerShell: right-click once inside the window.


====================================================================
PART 0 - OPEN POWERSHELL AND LOG IN TO THE PI
====================================================================

1. Click the Start button (the Windows logo), type  PowerShell  and
   press Enter. A window with text opens.

2. Type this and press Enter:

        ssh PIUSER@PIADDRESS

3. Type the Pi's password (nothing shows) and press Enter.

When you see a line ending in a dollar sign, like  sam@mypi:~$  you
are "inside" the Pi. Everything you type now happens on the Pi.

Mac users: open "Terminal" instead of PowerShell. Everything else is
the same.


====================================================================
PART 1 - SAVE A COPY OF YOUR TICKETS  (optional but recommended)
====================================================================

Skip this part only if you are SURE you will never need your tickets
or logins again.

1. On the Pi, type these three lines, one at a time (Enter after
   each):

        mkdir -p ~/helpdesk-backup
        cd ~/helpdesk-v4
        cp tickets.json users.json ~/helpdesk-backup/

   If it says "No such file or directory", Helpdesk is not installed
   where expected - see Part 3 note and skip to Part 4.

2. Check the copies exist:

        ls ~/helpdesk-backup

   You should see  tickets.json  and  users.json .

3. Copy them to your Windows computer. First leave the Pi by typing:

        exit

   You are back in PowerShell on your own computer. Now type this
   (with your blanks filled in):

        scp -r PIUSER@PIADDRESS:helpdesk-backup "$env:USERPROFILE\Desktop\"

   (Mac users:  scp -r PIUSER@PIADDRESS:helpdesk-backup ~/Desktop/ )

   Type the Pi's password. A folder called  helpdesk-backup  appears
   on your Desktop. You can open  tickets.json  with Notepad to read
   your tickets as text.

   Keep that folder somewhere safe (a USB stick is perfect).

4. Log in to the Pi again for the next parts:

        ssh PIUSER@PIADDRESS


====================================================================
PART 2 - STOP HELPDESK AND STOP IT STARTING BY ITSELF
====================================================================

Type this one line and press Enter (it may ask for the Pi's password):

        sudo systemctl disable --now helpdesk

You will see a line like "Removed ... helpdesk.service" - good.

If you see "Failed to disable unit: Unit file helpdesk.service does
not exist", you never installed it as a service. That is fine; carry
on to Part 3.

If you ran Helpdesk by hand in a window instead, click in that window
and press  Ctrl+C  to stop it.


====================================================================
PART 3 - REMOVE THE "START BY ITSELF" SETTING
====================================================================

Type these three lines, one at a time, Enter after each:

        sudo rm -f /etc/systemd/system/helpdesk.service
        sudo rm -f /etc/helpdesk.env
        sudo systemctl daemon-reload

(They print nothing when they work. "rm -f" does not complain if a
file is not there, so you cannot do any harm.)

The second line also removes the settings file that holds, for
example, the "no password" setting from Install.txt Part 11. If you
had turned the password off, it is now back on - and gone with the
rest.


====================================================================
PART 4 - DELETE THE HELPDESK FOLDER
====================================================================

THIS PART DELETES YOUR TICKETS FOR GOOD. There is no "undo" and no
recycle bin. Did you do Part 1? If not, stop and do it now.

1. First look at what you are about to delete:

        ls ~/helpdesk-v4

   You should see files such as  server.js  and  public  and
   tickets.json . If it says "No such file or directory", the folder
   is already gone - skip to Part 5.

2. Delete it. Type this line EXACTLY - be careful with the spaces:

        rm -rf ~/helpdesk-v4

   (It prints nothing when it works.)

3. Delete the zip file you sent over during install:

        rm -f ~/helpdesk-v4.zip

4. If you came from the OLD version 3, its folder is probably still
   there too (Update.txt, Part 1 left it on purpose as a spare copy).
   It holds an old copy of your tickets. Look for it:

        ls -d ~/helpdesk-v3 ~/shared/helpdesk-v3

   If you see it and you are SURE you do not need it any more:

        rm -rf ~/helpdesk-v3

   (Change the path to whichever one  ls  showed you.)

   The  backup-  folders that updates made are INSIDE the helpdesk-v4
   folder, so step 2 already deleted them.


====================================================================
PART 5 - OPTIONAL: REMOVE THE PROGRAMS THE SETUP INSTALLED
====================================================================

The setup may have installed two small helper programs: "unzip" and
"Node.js" (the engine Helpdesk ran on). Leaving them is harmless. They
take very little room. Only remove them if you want the Pi as clean
as before.

Do NOT remove Node.js if you are not sure whether something else on
the Pi uses it. When in doubt, skip this part.

To remove Node.js:

        sudo apt remove -y nodejs npm
        sudo apt autoremove -y

To remove unzip:

        sudo apt remove -y unzip

(They print a lot of text. That is normal.)


====================================================================
PART 6 - IF YOU USED EMAIL NOTIFICATIONS: REVOKE THE GOOGLE PASSWORD
====================================================================

If you turned on email notifications (START-HERE.txt, "Email"), you
gave Helpdesk a special 16-letter "app password" from Google. Even
though Helpdesk is gone, that password still exists. Cancel it:

1. In a web browser, sign in to the Gmail account you used.
2. Go to   https://myaccount.google.com/apppasswords
3. Find the entry named  Helpdesk  and click the trash can (or
   "Remove") next to it.

If you never turned on email, skip this part.


====================================================================
PART 7 - CHECK THAT IT IS REALLY GONE
====================================================================

1. Type:

        sudo systemctl status helpdesk

   You want to see:   Unit helpdesk.service could not be found.

2. Type:

        ls ~/helpdesk-v4

   You want to see:   No such file or directory

3. On any computer, open the Helpdesk web address in a browser. You
   want the browser to say something like "This site can't be
   reached" or "Unable to connect". That means Helpdesk is gone.

4. Tell your team that the Helpdesk address no longer works, and
   delete any bookmarks to it. If you printed HOW-TO-GET-HELP.txt,
   take the copies down.

You are finished. To leave the Pi, type:

        exit

A few old lines about Helpdesk may stay in the Pi's system log for a
while. That is harmless; the Pi deletes old log lines by itself.


====================================================================
PART 8 - "I ONLY WANT TO START OVER" (keep Helpdesk installed)
====================================================================

Choose ONE of these. Both need you to be logged in to the Pi (see
Part 0).

A) EMPTY ALL TICKETS, KEEP THE PEOPLE AND LOGINS
   (Ticket numbers start again from HD-001.)

        sudo systemctl stop helpdesk
        rm -f ~/helpdesk-v4/tickets.json
        sudo systemctl start helpdesk

B) START COMPLETELY FRESH - NO TICKETS, NO LOGINS
   (A new first-run password is created, like on a brand new install.)

        sudo systemctl stop helpdesk
        rm -f ~/helpdesk-v4/tickets.json ~/helpdesk-v4/users.json
        sudo systemctl start helpdesk
        sleep 5
        sudo journalctl -u helpdesk -n 40 --no-pager | grep -E 'username|password'

   The last lines show the new username and one-time password. If
   you see several, use the BOTTOM-most one (the newest). Then log in
   as in Install.txt, Part 8.

Wondering about a save first? Do Part 1 before either choice.


====================================================================
PART 9 - "I CHANGED MY MIND - PUT IT BACK"
====================================================================

1. Follow Install.txt from the start. It works the same as the first
   time.

2. To bring your OLD tickets and logins back (only if you saved them
   in Part 1), do this AFTER the install is finished. First copy the
   backup folder from your Desktop to the Pi. In PowerShell on your
   own computer:

        scp -r "$env:USERPROFILE\Desktop\helpdesk-backup" PIUSER@PIADDRESS:~

   Then log in to the Pi (ssh PIUSER@PIADDRESS) and type:

        sudo systemctl stop helpdesk
        cd ~/helpdesk-backup
        cp tickets.json users.json ~/helpdesk-v4/
        chmod 600 ~/helpdesk-v4/tickets.json ~/helpdesk-v4/users.json
        sudo systemctl start helpdesk

   Your old tickets and logins are back. Use your OLD passwords (the
   new first-run password is replaced by your old logins).


====================================================================
PROBLEMS
====================================================================

"Permission denied" when typing a command that starts with "sudo":
   Wrong Pi password, or you are not allowed to use sudo. Ask whoever
   looks after your Pi.

"Could not resolve hostname", "Connection timed out", "Connection
refused", or "Permission denied, please try again" when logging in:
   See Install.txt, PART 12 - the same fixes apply.

"No such file or directory" for a command in Part 1 or 4:
   The folder is not in the usual place, or is already deleted. That
   is not a problem for Part 4 - it just means there is nothing left
   to delete.

You deleted something by accident:
   Files removed with "rm" cannot be recovered. If you saved a backup
   (Part 1), use Part 9. Otherwise, install again from Install.txt.
